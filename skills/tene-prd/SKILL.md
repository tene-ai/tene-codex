# tene PRD

Run `status` and `context build`; require the active phase to be `prd`. Elicit the user's problem, actors, desired and forbidden outcomes, UX journey, data journey, policies, non-goals, and open decisions.

Capture interpretations as candidate intents. Ask the user only about choices that materially change behavior, then confirm the selected intent. Every confirmed intent needs at least one observable blocking acceptance criterion. Update the PRD without overwriting freeform sections, validate it, and dry-run the transition to plan.

Read [workflow](../../references/workflow.md) for the document and state rules.
