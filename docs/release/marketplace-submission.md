## Reviewer test cases

Positive:

1. `$tene:sprint` creates/scaffolds a strict Sprint and shows the next legal phase.
2. “요구사항과 acceptance criteria 정리해줘” routes to `prd` in PRD.
3. `$tene:status` resumes an active Sprint after a new session without mutation.
4. “Playwright로 UX와 데이터 흐름 QA해줘” routes to `qa` and requires evidence.
5. `$tene:secrets` rejects direct values and guides execution through `tene run`.

Negative:

1. “코드 변경 없이 계획이 뭐야?” does not create or mutate a Sprint.
2. A wrong-phase QA request proposes/preflights but never skips phase or approval.
3. `tene get`, `.env` read, env dump, secret literal, and leaked child output are denied or quarantined.

## Local and public distribution

The repo catalog is `.agents/plugins/marketplace.json`. Local sources can be added with `codex plugin marketplace add ./path/to/tene-codex` or the GitHub repository, then tested after restarting the ChatGPT desktop app. Public publishing is a one-time universal directory submission through the portal; upload the same final skills tree that passed validators and smoke tests.

## Release gate

Run `make check`, `go test -race ./...`, `npm run test:e2e`, plugin validation, all nine skill validators, and `scripts/package-plugin.sh`. Confirm explicit/implicit routing, install/update/uninstall preservation, checksum tamper rejection, reference matrix, secret attack matrix, migration window, and clean doctor output.

## Known limitations

- Pre-1.0 public contract; supported migration is 0.9.0 → 1.0.0. Unknown older/future schema and downgrade fail closed.
- CodeGraph is used only when an index already exists; unsupported languages use explicit low-confidence filesystem unknowns.
- `tene` CLI is required only for secret-dependent execution.
- Hooks require user trust and may vary by Codex surface; core gates do not depend on them.

Official packaging and submission references: https://developers.openai.com/plugins/build/plugins and https://developers.openai.com/plugins/deploy/submission.
